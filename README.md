# Angelika Kyle's Portfolio

This is my personal portfolio website, built to showcase my work as a full-stack developer, software engineer, and AI engineer.

The site highlights my projects, technical stack, resume, and contact information in a creative and interactive way. It was designed to feel clean, modern, and a little more personal than a typical portfolio.

## Live Site

[angelikakyle.netlify.app](https://angelikakyle.netlify.app)

## What’s Inside

- Interactive homepage
- Project showcase
- Tech stack section
- Light and dark mode
- Command palette
- Resume link
- Contact form and social links
- Responsive layout for desktop and mobile

## Tech Stack

- React
- TypeScript
- Vite
- CSS
- Lucide React
- Netlify
